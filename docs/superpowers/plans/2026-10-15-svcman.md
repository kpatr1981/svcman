# svcman Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `svcman`, a Go TUI and audit tool that manages and checks systemd services and timers on remote hosts over SSH, in the same fashion as `cronman`.

**Architecture:** One Go `main` package in `personal/tools/svcmanager`. Everything on the target runs as POSIX `sh` scripts sent through the user's system `ssh` (the `Runner` copied from cronman). Pure parsers and checks (`units.go`, `checks.go`, `probe.go` parsing, `dropin.go` rendering) are unit-tested on fixtures captured from real systemd. Remote behaviour is tested end to end on Lima VMs.

**Tech Stack:** Go 1.26 (module `go 1.26.0`, as cronman), `golang.org/x/term`, `golang.org/x/sys` (Windows console only), Lima VMs (Debian 12, Rocky 9) for integration tests.

**Spec:** `docs/superpowers/specs/2026-10-15-svcman-design.md`

## Global Constraints

- Module path `github.com/kpatr1981/svcman`; binary `svcman`; version `0.1.0`.
- Every Go file starts with `// svcman — Author: Konstantinos Patronas <kpatronas@gmail.com>` (main.go has the longer cronman-style header).
- No third-party dependencies beyond `golang.org/x/term` and `golang.org/x/sys`.
- Nothing is installed on the target. Remote code is POSIX `sh`, GNU coreutils and systemd tools only (target is Linux with systemd ≥ 230).
- Every remote `systemctl`/`journalctl` call runs with `LC_ALL=C TZ=UTC SYSTEMD_PAGER= SYSTEMD_COLORS=0`, or `--no-pager` where noted.
- svcman writes only `/etc/systemd/system/<unit>.d/svcman.conf` and backups in `<login home>/.svcman_backups/`. Vendor unit files and other drop-ins are never written.
- Every state-changing action and every fix asks before running.
- Client builds for linux/darwin/windows × amd64/arm64 with `CGO_ENABLED=0`.
- cronman (`../cronmanager`) is read-only for this plan. Files are copied from it, never edited in place.
- Two refinements to the spec, applied to the spec in Task 1:
  - (a) The interactive probe runs before the screen opens, for the same units audit checks (enabled, failed, timer-linked). Other units are probed when their details open, and the CHECK column shows `·` until then.
  - (b) When sudo needs a password, svcman reads it locally (hidden) once per session and feeds it to `sudo -k -S -p ''`, as cronman's audit does. This replaces `Runner.Interactive("sudo …")`, so command output can be captured.

## Review Focus

1. **A host with hundreds of units, including template instances (`getty@tty1.service`) and names with `\x2d` escapes.** The load must neither drop nor choke on them, and template files (`foo@.service`) must be skipped. Pinned in Task 3 (`TestLoadScriptSkipsTemplates`, fixture with instances).
2. **A unit whose `ExecStart` has several commands, `-`/`@`/`+` prefixes, or arguments that contain ` ; `.** The parser must keep each command's path. Pinned in Task 3 (`TestParseExecMulti`).
3. **The drop-in on disk was changed by someone else (or by `systemctl edit`) after svcman loaded it.** Save must refuse that unit and keep the user's edits. Pinned in Task 8 (`TestSaveScriptRefusesChangedFile`).
4. **`daemon-reload` fails after the write.** The old drop-in must come back, or the new one must be removed. Pinned in Task 8 (`TestSaveScriptRollsBackOnReloadFailure`).
5. **The login user has no sudo, or sudo needs a password and the user leaves it empty.** Read-only use must still work: list, checks marked approximate, journal limited. Actions must fail with a clear message, never hang waiting on a hidden sudo prompt. Pinned in Task 6 (`TestRunRootNeedsPassword`, `TestRunRootNeverPromptsRemotely`).

```go
// svcman — Author: Konstantinos Patronas <kpatronas@gmail.com>

package main

// Severity of a check result; higher is worse.
type Severity int

const (
	SevUnknown Severity = iota // not checked
	SevOK
	SevInfo
	SevWarn
	SevFail
)

// Fix is a shell command, run as root on the target, that resolves an Issue.
type Fix struct {
	Label string
	Cmd   string
}

// Issue is one problem found with a unit or a host.
type Issue struct {
	Sev   Severity
	Text  string
	Fixes []Fix
}

// worst returns the highest severity in is, or SevOK when is is empty.
func worst(is []Issue) Severity {
	w := SevOK
	for _, i := range is {
		if i.Sev > w {
			w = i.Sev
		}
	}
	return w
}
```

import (

func TestParseShowBlocks(t *testing.T) {
	out := `Id=a.service
Type=simple
LoadState=loaded
ActiveState=failed
SubState=failed
Result=exit-code
UnitFileState=enabled
FragmentPath=/etc/systemd/system/a.service
DropInPaths=/etc/systemd/system/a.service.d/x.conf /etc/systemd/system/a.service.d/svcman.conf
ExecStart={ path=/opt/a/run ; argv[]=/opt/a/run --x ; ignore_errors=no ; start_time=[n/a] ; stop_time=[n/a] ; pid=0 ; code=(null) ; status=0/0 }
User=app
EnvironmentFiles=/etc/default/a (ignore_errors=yes)
EnvironmentFiles=/etc/a.env (ignore_errors=no)
NRestarts=7
TriggeredBy=a.timer
NeedDaemonReload=yes
StateChangeTimestamp=Thu 2026-10-15 02:00:00 UTC

Id=a.timer
LoadState=loaded
ActiveState=active
Triggers=a.service
NextElapseUSecRealtime=Fri 2026-10-16 03:00:00 UTC
LastTriggerUSec=n/a
`
	us := parseShow(out)
	if len(us) != 2 {
		t.Fatalf("got %d units", len(us))
	}

		t.Errorf("bad states: %+v", a)

		t.Errorf("dropins %v", a.DropIns)

// ExecCmd is one command of an Exec*= setting.
type ExecCmd struct {
	Key          string // ExecStart, ExecStartPre, ...
	Path         string // the executable systemd runs
	Argv         string // the command line as systemd shows it
	IgnoreErrors bool   // "-" prefix
}

// EnvFile is one EnvironmentFile= entry.
type EnvFile struct {
	Path     string
	Optional bool // "-" prefix
}

// Unit is a service or timer as systemctl show describes it.
type Unit struct {
	Name, Kind, Description, Type        string
	Load, Active, Sub, Result, FileState string
	Fragment                             string
	DropIns                              []string
	Exec                                 []ExecCmd
	User, Group                          string
	DynamicUser                          bool
	WorkDir                              string
	EnvFiles                             []EnvFile
	NRestarts                            int
	Restart                              string
	Triggers, TriggeredBy                []string
	Wants, Requires                      []string
	StateChange, NextElapse, LastTrigger time.Time
	NeedReload                           bool
}

// parseShow splits systemctl show output (blank-line separated key=value
// blocks) into units. Blocks without Id= are dropped.
func parseShow(out string) []*Unit {
	var units []*Unit
	var cur map[string][]string
	flush := func() {
		if len(cur["Id"]) > 0 {
			units = append(units, unitFromProps(cur))
		}
		cur = nil
	}
	for _, l := range strings.Split(out, "\n") {
		l = strings.TrimRight(l, "\r")
		if l == "" {
			flush()
			continue
		}
		k, v, ok := strings.Cut(l, "=")
		if !ok {
			continue
		}
		if cur == nil {
			cur = map[string][]string{}
		}
		cur[k] = append(cur[k], v)
	}
	flush()
	return units
}

func unitFromProps(p map[string][]string) *Unit {
	get := func(k string) string {
		if v := p[k]; len(v) > 0 {
			return v[len(v)-1]
		}
		return ""
	}
	u := &Unit{
		Name: get("Id"), Description: get("Description"), Type: get("Type"),
		Load: get("LoadState"), Active: get("ActiveState"), Sub: get("SubState"),
		Result: get("Result"), FileState: get("UnitFileState"), Fragment: get("FragmentPath"),
		DropIns: strings.Fields(get("DropInPaths")),
		User:    get("User"), Group: get("Group"), DynamicUser: get("DynamicUser") == "yes",
		WorkDir: get("WorkingDirectory"), Restart: get("Restart"),
		Triggers: strings.Fields(get("Triggers")), TriggeredBy: strings.Fields(get("TriggeredBy")),
		Wants: strings.Fields(get("Wants")), Requires: strings.Fields(get("Requires")),
		StateChange: parseTime(get("StateChangeTimestamp")),
		NextElapse:  parseTime(get("NextElapseUSecRealtime")),
		LastTrigger: parseTime(get("LastTriggerUSec")),
		NeedReload:  get("NeedDaemonReload") == "yes",
	}
	u.Kind = strings.TrimPrefix(path.Ext(u.Name), ".")
	u.NRestarts, _ = strconv.Atoi(get("NRestarts"))
	for _, k := range execKeys {
		for _, v := range p[k] {
			u.Exec = append(u.Exec, parseExec(k, v)...)
		}
	}
	for _, v := range p["EnvironmentFiles"] {
		f, rest, _ := strings.Cut(v, " ")
		if f != "" {
			u.EnvFiles = append(u.EnvFiles, EnvFile{Path: f, Optional: strings.Contains(rest, "ignore_errors=yes")})
		}
	}
	return u
}

// argv[]= runs up to " ; ignore_errors=", so arguments containing " ; " survive.
var execRe = regexp.MustCompile(`path=(\S+) ; argv\[\]=(.*?) ; ignore_errors=(yes|no)`)

// parseExec reads one Exec*= value, which may hold several { ... } commands.
func parseExec(key, v string) []ExecCmd {
	var out []ExecCmd
	for _, m := range execRe.FindAllStringSubmatch(v, -1) {
		out = append(out, ExecCmd{Key: key, Path: m[1], Argv: m[2], IgnoreErrors: m[3] == "yes"})
	}
	return out
}

// parseTime reads a systemd timestamp printed with TZ=UTC LC_ALL=C.
func parseTime(s string) time.Time {
	t, err := time.Parse("Mon 2006-01-02 15:04:05 MST", s)
	if err != nil {
		return time.Time{}
	}
	return t
}

package main

import (
	"fmt"
	"strconv"
	"strings"
	"time"
)

// Priv is how svcman can become root on the host.
type Priv int

const (
	PrivNone     Priv = iota // not root, no sudo
	PrivRoot                 // logged in as root
	PrivNoPass               // passwordless sudo
	PrivPassword             // sudo asks for a password
)

// envC makes systemctl/journalctl output stable and parseable.
const envC = "LC_ALL=C TZ=UTC SYSTEMD_PAGER= SYSTEMD_COLORS=0"

// Host is one target machine and its units.
type Host struct {
	r           Runner
	Login       string
	Home        string
	Priv        Priv
	SysState    string
	Now         time.Time
	Units       []*Unit
	pw          string
	journalRoot bool
}

const loadScript = `command -v systemctl >/dev/null 2>&1 || { echo @@NOSYSTEMD; exit 0; }
export ` + envC + `
echo @@INFO
date +%s
id -un
echo "$HOME"
if [ "$(id -u)" = 0 ]; then echo root
elif command -v sudo >/dev/null 2>&1 && sudo -n true 2>/dev/null; then echo nopass
elif command -v sudo >/dev/null 2>&1; then echo pass
else echo none; fi
s=$(systemctl is-system-running 2>/dev/null); echo "${s:-unknown}"
echo @@SHOW
{ systemctl list-units --all --type=service,timer --plain --no-legend --no-pager 2>/dev/null
  systemctl list-unit-files --type=service,timer --no-legend --no-pager 2>/dev/null
} | sed 's/^[^a-zA-Z0-9_]* *//' | awk '{print $1}' | grep -E '\.(service|timer)$' | grep -v '@\.' | sort -u |
  tr '\n' '\0' | xargs -0 -r systemctl show --no-pager -p ` + showProps + ` 2>/dev/null
`

// loadHost reads everything svcman shows about the host in one round trip.
func loadHost(r Runner) (*Host, error) {
	out, errOut, err := RunScript(r, "", loadScript)
	if err != nil && !strings.Contains(out, "@@INFO") && !strings.Contains(out, "@@NOSYSTEMD") {
		if m := strings.TrimSpace(errOut); m != "" {
			return nil, fmt.Errorf("%s: %s", r.Label(), m)
		}
		return nil, err
	}
	h, perr := parseLoad(out)
	if perr != nil {
		return nil, fmt.Errorf("%s: %v", r.Label(), perr)
	}
	h.r = r
	return h, nil
}

func parseLoad(out string) (*Host, error) {
	if strings.Contains(out, "@@NOSYSTEMD") {
		return nil, fmt.Errorf("no systemd on this host (svcman needs Linux with systemd 230 or newer)")
	}
	_, rest, ok := strings.Cut(out, "@@INFO\n")
	if !ok {
		return nil, fmt.Errorf("unexpected output from the host")
	}
	info, show, _ := strings.Cut(rest, "@@SHOW\n")
	f := strings.Split(strings.TrimRight(info, "\n"), "\n")
	if len(f) < 5 {
		return nil, fmt.Errorf("unexpected output from the host")
	}
	h := &Host{Login: f[1], Home: f[2], SysState: f[4]}
	if n, err := strconv.ParseInt(f[0], 10, 64); err == nil {
		h.Now = time.Unix(n, 0).UTC()
	}
	h.Priv = map[string]Priv{"root": PrivRoot, "nopass": PrivNoPass, "pass": PrivPassword}[f[3]]
	h.Units = parseShow(show)
	return h, nil
}

// Unit returns the named unit, or nil.
func (h *Host) Unit(name string) *Unit {
	for _, u := range h.Units {
		if u.Name == name {
			return u
		}
	}
	return nil
}

// refresh re-reads the named units and replaces them in h.Units.
func (h *Host) refresh(names ...string) error {
	var q []string
	for _, n := range names {
		q = append(q, shq(n))
	}
	out, errOut, err := RunScript(h.r, "", envC+" systemctl show --no-pager -p "+showProps+" "+strings.Join(q, " "))
	if err != nil {
		return fmt.Errorf("%v %s", err, strings.TrimSpace(errOut))
	}
	for _, nu := range parseShow(out) {
		replaced := false
		for i, u := range h.Units {
			if u.Name == nu.Name {
				h.Units[i] = nu
				replaced = true
			}
		}
		if !replaced {
			h.Units = append(h.Units, nu)
		}
	}
	return nil
}

	if u.Kind == "service" && u.FileState == "enabled" && u.Active == "inactive" &&
		len(u.TriggeredBy) == 0 && u.Type != "oneshot" {

	}
	if u.NeedReload {
		add(SevWarn, "unit file changed on disk; systemd needs a daemon-reload", Fix{"reload systemd", "systemctl daemon-reload"})
	}
	if u.Kind == "timer" {
		for _, t := range u.Triggers {
			tu := h.Unit(t)
			if tu == nil || tu.Load == "not-found" {
				add(SevFail, "triggers "+t+", which does not exist")
				continue
			}
			if tu.Result != "" && tu.Result != "success" {
				add(SevWarn, fmt.Sprintf("last run of %s failed (%s)", t, tu.Result))
			}
		}
		if u.Active == "active" && !u.NextElapse.IsZero() && h.Now.Sub(u.NextElapse) > 5*time.Minute {
			add(SevWarn, "overdue: it should have triggered at "+u.NextElapse.Format("2006-01-02 15:04")+" UTC",
				Fix{"restart the timer", "systemctl restart " + q})
		}
	}
	if f != nil {
		is = append(is, checkFacts(u, f)...)
	}
	return is

package main

import (
	"errors"
	"fmt"
	"strings"
)

var (
	errNeedPassword = errors.New("needs the sudo password")
	errNoRoot       = errors.New("needs root, and sudo is not available")
)

// canRoot reports whether runRoot works without asking for anything.
func (h *Host) canRoot() bool {
	return h.Priv == PrivRoot || h.Priv == PrivNoPass || (h.Priv == PrivPassword && h.pw != "")
}

// runRoot runs a sh script as root: directly, with sudo -n, or with the sudo
// password typed earlier on stdin. sudo never prompts on the remote side.
func (h *Host) runRoot(script string) (string, string, error) {
	switch {
	case h.Priv == PrivRoot:
		return RunScript(h.r, "", script)
	case h.Priv == PrivNoPass:
		return RunScript(h.r, "sudo -n", script)
	case h.Priv == PrivPassword && h.pw != "":
		return h.r.Exec("sudo -k -S -p '' sh -c "+shq(script), h.pw+"\n")
	case h.Priv == PrivPassword:
		return "", "", errNeedPassword
	}
	return "", "", errNoRoot
}

// setPassword checks pw with sudo and keeps it for later root commands.
func (h *Host) setPassword(pw string) error {
	out, _, _ := h.r.Exec("sudo -k -S -p '' sh -c 'echo SUDO_OK'", pw+"\n")
	if !strings.Contains(out, "SUDO_OK") {
		return fmt.Errorf("sudo authentication failed on %s", h.r.Label())
	}
	h.pw = pw
	return nil
}

// action runs "systemctl <verb> <units>" as root. On failure the error text
// is systemctl's own message on one line.
func (h *Host) action(verb string, units ...string) (string, error) {
	cmd := envC + " systemctl " + verb
	for _, u := range units {
		cmd += " " + shq(u)
	}
	out, errOut, err := h.runRoot(cmd + " 2>&1")
	if err != nil {
		if errors.Is(err, errNeedPassword) || errors.Is(err, errNoRoot) {
			return "", err
		}
		if m := oneLine(out + " " + errOut); m != "" {
			return out, errors.New(m)
		}
		return out, err
	}
	return out, nil
}

func oneLine(s string) string { return strings.Join(strings.Fields(s), " ") }

  g) { getent group "$path" || grep -q "^$path:" /etc/group; } >/dev/null 2>&1 && e=1 || e=0; printf 'F\t%s\texists=%s\n' "$idx" "$e"; continue ;;

     printf 'F\t%s\texists=%s\n' "$idx" "$e"; continue ;;
  v) command -v systemd-analyze >/dev/null 2>&1 || continue
     systemd-analyze verify "$path" 2>&1 | grep -v '^$' | head -5 | while IFS= read -r l; do printf 'V\t%s\t%s\n' "$idx" "$l"; done
     continue ;;
  esac
  if [ ! -e "$path" ]; then
    if [ -L "$path" ]; then s=broken-link; else s=missing; fi
    printf 'F\t%s\texists=0 state=%s\n' "$idx" "$s"; continue
  fi
  set -- $(st "$path"); mode=$1 own=$2 grp=$3
  if [ -d "$path" ]; then t=dir; elif [ -f "$path" ]; then t=file; else t=other; fi
  x=
  case $kind in x|d) x="access=$(as "$user" -x "$path")" ;; r) x="access=$(as "$user" -r "$path")" ;; esac
  if [ "$kind" = x ] && [ "$t" = file ]; then
    l1=$(head -n1 "$path" 2>/dev/null | head -c 200)
    case $l1 in '#!'*)
      i=$(printf '%s' "$l1" | sed 's/^#! *//; s/[ '"$CR"'].*//')
      if [ -x "$i" ]; then x="$x interp=$i interp_ok=1"; else x="$x interp=$i interp_ok=0"; fi
      if [ "$i" = /usr/bin/env ]; then
        a=$(printf '%s' "$l1" | tr -d "$CR" | awk '{print $2}')
        if (PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin; command -v "$a") >/dev/null 2>&1; then o=1; else o=0; fi
        x="$x envcmd=$a envcmd_ok=$o"
      fi
      head -c 4096 "$path" 2>/dev/null | grep -q "$CR" && x="$x crlf=1"
      x="$x access_r=$(as "$user" -r "$path")" ;;
    esac
    if command -v findmnt >/dev/null 2>&1 && findmnt -n -o OPTIONS -T "$path" 2>/dev/null | tr , '\n' | grep -qx noexec; then x="$x noexec=1"; fi
  fi
  printf 'F\t%s\texists=1 type=%s mode=%s owner=%s group=%s %s\n' "$idx" "$t" "$mode" "$own" "$grp" "$x"
done `

// probeScript returns a sh script that checks every request; one output line
// per request ("F\t<idx>\tkey=value ...") plus "V\t<idx>\t<line>" for verify.
func probeScript(reqs []probeReq) string {
	var data strings.Builder
	for i, r := range reqs {
		fmt.Fprintf(&data, "%d\t%c\t%s\t%s\n", i, r.Kind, r.Path, r.User)
	}
	start, body := heredoc(data.String())
	return probeFuncs + start + "\n" + body
}

func parseProbe(out string, reqs []probeReq) map[string]*UnitFacts {
	m := map[string]*UnitFacts{}
	get := func(i int) *UnitFacts {
		u := reqs[i].Unit
		if m[u] == nil {
			m[u] = &UnitFacts{}
		}
		return m[u]
	}
	for _, l := range strings.Split(out, "\n") {
		parts := strings.SplitN(l, "\t", 3)
		if len(parts) != 3 {
			continue
		}
		i, err := strconv.Atoi(parts[1])
		if err != nil || i < 0 || i >= len(reqs) {
			continue
		}
		switch parts[0] {
		case "V":
			uf := get(i)
			uf.Verify = append(uf.Verify, parts[2])
		case "F":
			f := Fact{Req: reqs[i]}
			for _, kv := range strings.Fields(parts[2]) {
				k, v, _ := strings.Cut(kv, "=")
				switch k {
				case "exists":
					f.Exists = v == "1"
				case "state":
					f.State = v
				case "type":
					f.Type = v
				case "mode":
					n, _ := strconv.ParseInt(v, 8, 32)
					f.Mode = int(n)
				case "owner":
					f.Owner = v
				case "group":
					f.Group = v
				case "access":
					f.Access = v
				case "access_r":
					f.AccessR = v
				case "interp":
					f.Interp = v
				case "interp_ok":
					f.InterpOK = v == "1"
				case "envcmd":
					f.EnvCmd = v
				case "envcmd_ok":
					f.EnvCmdOK = v == "1"
				case "crlf":
					f.CRLF = v == "1"
				case "noexec":
					f.NoExec = v == "1"
				}
			}
			uf := get(i)
			uf.Facts = append(uf.Facts, f)
		}
	}
	return m
}

// probe checks the files and users of units, as root when that works
// without asking (exact per-user tests), otherwise as the login user
// (access results are then marked approx-).
func (h *Host) probe(units []*Unit) (map[string]*UnitFacts, error) {
	var reqs []probeReq
	for _, u := range units {
		reqs = append(reqs, requests(u)...)
	}
	if len(reqs) == 0 {
		return map[string]*UnitFacts{}, nil
	}
	script := probeScript(reqs)
	var out string
	var err error
	if h.canRoot() {
		out, _, err = h.runRoot(script)
	} else {
		out, _, err = RunScript(h.r, "", script)
	}
	if err != nil && out == "" {
		return nil, err
	}
	m := parseProbe(out, reqs)
	for _, u := range units { // a unit with no findings still counts as probed
		if m[u.Name] == nil {
			m[u.Name] = &UnitFacts{}
		}
	}
	return m, nil
}

// chmodFix adds the missing permission bit for the class the unit's user
// falls in (owner, else others; group membership is not probed). It returns
// nil when that bit is already set, because then something else (a parent
// directory, ACL, mount) blocks access and chmod on the file would not help.
func chmodFix(f Fact, bit string) *Fix {
	mask := map[string]int{"r": 4, "x": 1}[bit]
	who, shift := "o", 0
	if f.Req.User == "root" || f.Req.User == f.Owner {
		who, shift = "u", 6
	}
	if f.Mode&(mask<<shift) != 0 {
		return nil
	}
	return &Fix{"chmod " + who + "+" + bit, "chmod " + who + "+" + bit + " " + shq(f.Req.Path)}
}

// svcman — Author: Konstantinos Patronas <kpatronas@gmail.com>

package main

import (
	"errors"
	"fmt"
	"strings"
)

const unitDir = "/etc/systemd/system"

const dropInHeader = "# Managed by svcman. Delete this file to undo.\n"

// Entry is one Key=value line of a drop-in.
type Entry struct{ Section, Key, Value string }

// DropIn is svcman's own drop-in for one unit.
type DropIn struct {
	Unit    string
	Path    string
	Orig    string // content as loaded ("" when there was no file)
	Exists  bool
	Entries []Entry
	base    string // Render() of the loaded entries
}

func dropInPath(unit string) string { return unitDir + "/" + unit + ".d/svcman.conf" }

// isResetKey: settings that add to the vendor value unless reset first.
func isResetKey(k string) bool {
	switch k {
	case "ExecStartPre", "ExecStart", "ExecStartPost", "ExecReload", "ExecStop", "ExecStopPost":
		return true
	}
	return false
}

func parseDropIn(content string) []Entry {
	var es []Entry
	sec := ""
	for _, l := range strings.Split(content, "\n") {
		l = strings.TrimSpace(l)
		switch {
		case l == "" || strings.HasPrefix(l, "#") || strings.HasPrefix(l, ";"):
		case strings.HasPrefix(l, "[") && strings.HasSuffix(l, "]"):
			sec = l[1 : len(l)-1]
		default:
			k, v, ok := strings.Cut(l, "=")
			k, v = strings.TrimSpace(k), strings.TrimSpace(v)
			if !ok || (v == "" && isResetKey(k)) {
				continue // svcman writes the reset lines itself
			}
			es = append(es, Entry{sec, k, v})
		}
	}
	return es
}

func newDropIn(unit, content string, exists bool) *DropIn {
	d := &DropIn{Unit: unit, Path: dropInPath(unit), Orig: content, Exists: exists, Entries: parseDropIn(content)}
	d.base = d.Render()
	return d
}

// Render writes the entries grouped by section in first-seen order. The first
// value of an Exec* key in a section is preceded by an empty reset line.
func (d *DropIn) Render() string {
	if len(d.Entries) == 0 {
		return ""
	}
	var sections []string
	by := map[string][]Entry{}
	for _, e := range d.Entries {
		if _, ok := by[e.Section]; !ok {
			sections = append(sections, e.Section)
		}
		by[e.Section] = append(by[e.Section], e)
	}
	var b strings.Builder
	b.WriteString(dropInHeader)
	for i, s := range sections {
		if i > 0 {
			b.WriteString("\n")
		}
		b.WriteString("[" + s + "]\n")
		reset := map[string]bool{}
		for _, e := range by[s] {
			if isResetKey(e.Key) && !reset[e.Key] {
				b.WriteString(e.Key + "=\n")
				reset[e.Key] = true
			}
			b.WriteString(e.Key + "=" + e.Value + "\n")
		}
	}
	return b.String()
}

func (d *DropIn) Dirty() bool { return d.Render() != d.base }

// knownKey: unit-file keys whose systemctl show property has another name
// (RestartSec→RestartUSec, EnvironmentFile→EnvironmentFiles) count as known.
func knownKey(props map[string]bool, key string) bool {
	if props[key] || props[key+"s"] {
		return true
	}
	if strings.HasSuffix(key, "Sec") && props[strings.TrimSuffix(key, "Sec")+"USec"] {
		return true
	}
	return false
}

	if u.Kind == "timer" {
		return "Timer"
	}
	return "Service"
}

// loadDropIn reads svcman.conf for unit (world-readable, no root needed).
func loadDropIn(h *Host, unit string) (*DropIn, error) {
	p := shq(dropInPath(unit))
	out, _, err := RunScript(h.r, "", "if [ -e "+p+" ]; then echo @@YES; cat "+p+"; else echo @@NO; fi")
	if err != nil {
		return nil, err

	if rest, ok := strings.CutPrefix(out, "@@YES\n"); ok {
		return newDropIn(unit, rest, true), nil
	}

}

var errChanged = errors.New("changed on the host since it was loaded; reload (r) and edit again")

// saveScript guards against concurrent changes, backs up, writes atomically,
// reloads systemd, and rolls back if the reload fails. dir is unitDir except
// in tests. Output: "CHANGED", "BACKUP <path>", "BACKUPFAIL", "WRITEFAIL",
// "RELOADFAIL" or "OK".
func saveScript(dir string, d *DropIn, content, backupDir, owner, stamp string) string {
	ddir := dir + "/" + d.Unit + ".d"
	es, eb := heredoc(d.Orig)
	ns, nb := heredoc(content)
	existed := "0"
	if d.Exists {
		existed = "1"
	}
	return `f=` + shq(ddir+"/svcman.conf") + `; d=` + shq(ddir) + `; bk=` + shq(backupDir) + `; existed=` + existed + `
exp=$(mktemp) new=$(mktemp) cur=$(mktemp)
trap 'rm -f "$exp" "$new" "$cur"' EXIT
cat > "$exp" ` + es + "\n" + eb + `cat > "$new" ` + ns + "\n" + nb + `if [ -e "$f" ]; then
  [ "$existed" = 1 ] || { echo CHANGED; exit 3; }
  { cat "$f"; [ -n "$(tail -c1 "$f")" ] && echo; } > "$cur"
  cmp -s "$cur" "$exp" || { echo CHANGED; exit 3; }
elif [ "$existed" = 1 ]; then echo CHANGED; exit 3; fi
saved=
if [ -e "$f" ]; then
  saved="$bk/` + d.Unit + `-` + stamp + `.conf"
  mkdir -p "$bk" && cp -p "$f" "$saved" || { echo BACKUPFAIL; exit 4; }
  chown -R ` + shq(owner) + ` "$bk" 2>/dev/null || true
  echo "BACKUP $saved"
fi
if [ -s "$new" ]; then
  mkdir -p "$d" && cp "$new" "$d/.svcman.conf.tmp" && chmod 644 "$d/.svcman.conf.tmp" || { echo WRITEFAIL; exit 4; }
  chown 0:0 "$d/.svcman.conf.tmp" 2>/dev/null || true
  mv "$d/.svcman.conf.tmp" "$f" || { echo WRITEFAIL; exit 4; }
else
  rm -f "$f"; rmdir "$d" 2>/dev/null || true
fi
if ! systemctl daemon-reload >/dev/null 2>&1; then
  if [ -n "$saved" ]; then cp -p "$saved" "$f"; else rm -f "$f"; rmdir "$d" 2>/dev/null || true; fi
  systemctl daemon-reload >/dev/null 2>&1
  echo RELOADFAIL; exit 5
fi
echo OK
`
}

// saveDropIn writes d on the host as root; returns the backup path ("" when
// there was no previous file).
func saveDropIn(h *Host, d *DropIn, stamp string) (string, error) {
	out, errOut, err := h.runRoot(saveScript(unitDir, d, d.Render(), h.Home+"/.svcman_backups", h.Login, stamp))
	backup := ""
	for _, l := range strings.Split(out, "\n") {
		if p, ok := strings.CutPrefix(l, "BACKUP "); ok {
			backup = p
		}
	}
	switch {
	case strings.Contains(out, "CHANGED"):
		return "", errChanged
	case strings.Contains(out, "RELOADFAIL"):
		return backup, errors.New("daemon-reload failed; the previous drop-in was restored")
	case strings.Contains(out, "BACKUPFAIL"):
		return "", errors.New("could not back up " + d.Path + "; nothing written")
	case strings.Contains(out, "WRITEFAIL"):
		return backup, errors.New("could not write " + d.Path)
	case strings.Contains(out, "OK"):
		return backup, nil
	}
	if err == nil {
		err = errors.New("unexpected output")
	}
	return backup, fmt.Errorf("%v %s", err, oneLine(errOut))
}

package main

import (
	"strconv"
	"strings"
)

func journalCmd(unit string, n int, follow bool) string {
	c := envC + " journalctl --no-pager -o short-iso -n " + strconv.Itoa(n) + " -u " + shq(unit)
	if follow {
		c += " -f"
	}
	return c
}

// journal returns the unit's last n log lines. When the login user cannot
// see the system journal it retries as root (if that works without asking).
func (h *Host) journal(unit string, n int) ([]string, error) {
	cmd := journalCmd(unit, n, false)
	if !h.journalRoot {
		out, errOut, err := RunScript(h.r, "", cmd)
		limited := strings.Contains(errOut, "not seeing messages") || strings.Contains(errOut, "No journal files") ||
			strings.Contains(strings.ToLower(errOut), "permission")
		if !limited || !h.canRoot() {
			if err != nil && out == "" {
				return nil, err
			}
			return journalLines(out), nil
		}
		h.journalRoot = true
	}
	out, _, err := h.runRoot(cmd)
	if err != nil && out == "" {
		return nil, err
	}
	return journalLines(out), nil
}

func journalLines(out string) []string {
	var ls []string
	for _, l := range strings.Split(strings.TrimRight(out, "\n"), "\n") {
		if l != "" && l != "-- No entries --" {
			ls = append(ls, l)
		}
	}
	return ls
}

// followCmd is run with Runner.Interactive; it uses an interactive sudo when
// the journal needed root, because the user is at the terminal then.
func (h *Host) followCmd(unit string) string {
	c := journalCmd(unit, 50, true)
	if h.journalRoot && h.Priv != PrivRoot {
		return "sudo sh -c " + shq(c)
	}
	return c
}

// auditUnits picks the units worth checking: enabled, failed, timers and the

func auditUnits(h *Host, all bool) []*Unit {
	var out []*Unit
	for _, u := range h.Units {
		if all || u.FileState == "enabled" || u.FileState == "enabled-runtime" || u.Active == "failed" ||
			u.Kind == "timer" || len(u.TriggeredBy) > 0 && strings.HasSuffix(u.TriggeredBy[0], ".timer") || u.NeedReload {
			out = append(out, u)
		}
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Name < out[j].Name })
	return out
}

// hostIssues are problems of the host as a whole.
func hostIssues(h *Host) []Issue {
	var is []Issue
	switch h.SysState {
	case "degraded", "maintenance", "stopping":
		is = append(is, Issue{Sev: SevWarn, Text: "system state is " + h.SysState})
	}
	var failed []string
	for _, u := range h.Units {
		if u.Active == "failed" {
			failed = append(failed, u.Name)
		}
		if u.Load != "masked" {
			continue
		}
		for _, v := range h.Units {
			if v.FileState == "enabled" && (containsStr(v.Wants, u.Name) || containsStr(v.Requires, u.Name)) {
				is = append(is, Issue{Sev: SevWarn, Text: u.Name + " is masked but wanted by " + v.Name})
			}
		}
	}
	if len(failed) > 0 {
		is = append(is, Issue{Sev: SevFail, Text: fmt.Sprintf("%s: %s", plural(len(failed), "failed unit"), strings.Join(failed, ", "))})
	}
	return is
}

func containsStr(list []string, s string) bool {
	for _, x := range list {

		}

			return
		}
		if err := h.setPassword(pw); err != nil {

		}
	}
}

func runAudit(r Runner, o auditOpts) (int, error) {
	fmt.Fprintf(os.Stderr, "Connecting to %s…\n", r.Label())

		return 2, err
	}

	case PrivNone:
		fmt.Fprintln(os.Stderr, yellow("warning: not root and no sudo; file checks are judged from permission bits."))
	}

		fmt.Fprintln(os.Stderr, yellow("warning: continuing without root; file checks are judged from permission bits."))

		printIssue("", i)
	}

		is := Check(h, u, facts[u.Name])
		w := worst(is)
		if w == SevFail {
			failing++
		}
		if w == SevOK && !o.verbose {
			continue
		}
		fmt.Printf("\n%s  %s\n", bold(u.Name), dim("("+u.Active+", "+u.FileState+")"))
		if len(is) == 0 {
			fmt.Println("  " + sevMark(SevOK) + " " + sevLabel(SevOK))
		}
		for _, i := range is {
			printIssue("  ", i)

			fmt.Println(red("  failed: " + oneLine(out+" "+errOut)))
		default:
			fmt.Println(green("  done"))
		}
	}

package main

func key(k string) string { return bold(cyan(k)) }

func keybar(w int, items [][2]string) []string {
	var lines []string
	cur, curLen := " ", 1
	for _, it := range items {
		seg := key(it[0]) + " " + it[1]
		sl := visibleLen(seg)
		if curLen+sl+2 > w && curLen > 1 {
			lines = append(lines, cur)
			cur, curLen = " ", 1
		}
		if curLen > 1 {
			cur += "  "
			curLen += 2
		}
		cur += seg
		curLen += sl
	}
	return append(lines, cur)
}

// ask shows a question on the bottom lines and returns the key pressed (0 on esc).
func (a *app) ask(base func([]string) []string, question, choices string) rune {
	for {
		a.scr.draw(base([]string{" " + bold(question), " " + dim(choices)}), -1, -1)
		k, ok := a.scr.keys.Read()
		if !ok || k.Name == "esc" || k.Name == "ctrl-c" {
			return 0
		}
		if k.Name == "enter" {
			return '\n'
		}
		if k.Rune != 0 {
			return k.Rune
		}
	}
}

// prompt edits a value on the bottom lines; validate returns an error text or "".
func (a *app) prompt(base func([]string) []string, label, initial string, validate func(string) string) (string, bool) {
	ed := &lineEditor{buf: []rune(initial), pos: len([]rune(initial))}
	msg := ""
	for {
		w, _ := a.scr.size()
		head := " " + bold(label) + dim("  enter=accept  esc=cancel  ctrl-u clear")
		if msg != "" {
			head = " " + red(msg)
		}
		text, col := ed.view(w - 4)
		lines := base([]string{head, " " + cyan("›") + " " + text})
		a.scr.draw(lines, len(lines)-1, 3+col)
		k, ok := a.scr.keys.Read()
		if !ok {
			return "", false
		}
		done, cancel := ed.handle(k)
		if cancel {
			return "", false
		}
		if done {
			v := string(ed.buf)
			if validate != nil {
				if m := validate(v); m != "" {
					msg = m
					continue
				}
			}
			return v, true
		}
		msg = ""
	}
}

// pager shows lines with a title (startAtEnd: begin at the last page);
// extra handles keys other than scrolling and returns true to close it.
func (a *app) pager(title string, lines []string, keys [][2]string, startAtEnd bool, extra func(Key) bool) {
	off := 0
	if startAtEnd {
		off = len(lines) // clamped below
	}
	for {
		w, h := a.scr.size()
		bar := keybar(w, append(append([][2]string{}, keys...), [2]string{"↑↓ pgup/pgdn", "scroll"}, [2]string{"esc/q", "back"}))
		body := h - 2 - len(bar)
		if off > max(0, len(lines)-body) {
			off = max(0, len(lines)-body)
		}
		out := []string{inv(bold(" "+title+" ")) + " " + dim(a.h.r.Label())}
		for i := off; i < len(lines) && i < off+body; i++ {
			out = append(out, fit(lines[i], w))
		}
		for len(out) < h-len(bar)-1 {
			out = append(out, "")
		}
		out = append(out, dim(a.status))
		out = append(out, bar...)
		a.scr.draw(out, -1, -1)
		k, ok := a.scr.keys.Read()
		if !ok {
			return
		}
		a.status = ""
		switch {
		case k.Name == "up" || k.Rune == 'k':
			off = max(0, off-1)
		case k.Name == "down" || k.Rune == 'j':
			off++
		case k.Name == "pgup":
			off = max(0, off-body)
		case k.Name == "pgdn" || k.Rune == ' ':
			off += body
		case k.Name == "home" || k.Rune == 'g':
			off = 0
		case k.Name == "end" || k.Rune == 'G':
			off = len(lines)
		case k.Rune == 'q' || k.Name == "esc" || k.Name == "ctrl-c":
			return
		default:
			if extra != nil && extra(k) {
				return
			}
		}
	}
}

func wrapPrefixed(first, rest, text string, w int) []string {
	avail := max(20, w-visibleLen(first))
	var out []string
	r := []rune(text)
	prefix := first
	for len(r) > 0 {
		n := min(avail, len(r))
		if n < len(r) {
			if i := lastSpace(r[:n]); i > avail/2 {
				n = i + 1
			}
		}
		out = append(out, prefix+string(r[:n]))
		r = r[n:]
		prefix = rest
		avail = max(20, w-visibleLen(rest))
	}
	if len(out) == 0 {
		out = append(out, first)
	}
	return out
}

func lastSpace(r []rune) int {
	for i := len(r) - 1; i >= 0; i-- {
		if r[i] == ' ' {
			return i
		}
	}
	return -1
}

package main

import (
	"fmt"
	"os"
	"sort"
	"strings"
	"time"
)

var filters = []string{"all", "failed", "running", "enabled", "timers"}

type row struct {
	u     *Unit
	child bool // a timer's service, shown under the timer
}

type app struct {
	h        *Host
	scr      *screen
	rows     []row
	sel, off int
	filter   int
	search   string
	status   string
	facts    map[string]*UnitFacts
	edits    map[string]*DropIn
}

// buildRows orders units (failed first, then by name), puts each timer's
// service under it, and applies the filter and search.
func buildRows(h *Host, filter int, search string) []row {
	underTimer := map[string]bool{}
	for _, u := range h.Units {
		if u.Kind == "timer" {
			for _, t := range u.Triggers {
				if h.Unit(t) != nil {
					underTimer[t] = true
				}
			}
		}
	}
	top := make([]*Unit, 0, len(h.Units))
	for _, u := range h.Units {
		if !underTimer[u.Name] {
			top = append(top, u)
		}
	}
	sort.SliceStable(top, func(i, j int) bool {
		fi, fj := top[i].Active == "failed", top[j].Active == "failed"
		if fi != fj {
			return fi
		}
		return top[i].Name < top[j].Name
	})
	children := func(u *Unit) []*Unit {
		var cs []*Unit
		if u.Kind == "timer" {
			for _, t := range u.Triggers {
				if c := h.Unit(t); c != nil {
					cs = append(cs, c)
				}
			}
		}
		return cs
	}
	match := func(u *Unit) bool {
		cs := children(u)
		switch filters[filter] {
		case "failed":
			if u.Active == "failed" {
				return true
			}
			for _, c := range cs {
				if c.Active == "failed" || c.Result != "" && c.Result != "success" {
					return true
				}
			}
			return false
		case "running":
			return u.Sub == "running"
		case "enabled":
			return u.FileState == "enabled" || u.FileState == "enabled-runtime"
		case "timers":
			return u.Kind == "timer"
		}
		return true
	}
	var rows []row
	for _, u := range top {
		cs := children(u)
		if !match(u) {
			continue
		}
		if search != "" {
			hit := strings.Contains(u.Name, search)
			for _, c := range cs {
				hit = hit || strings.Contains(c.Name, search)
			}
			if !hit {
				continue
			}
		}
		rows = append(rows, row{u: u})
		for _, c := range cs {
			rows = append(rows, row{u: c, child: true})
		}
	}
	return rows
}

func (a *app) rebuild() {
	var cur string
	if u := a.current(); u != nil {
		cur = u.Name
	}
	a.rows = buildRows(a.h, a.filter, a.search)
	a.sel = 0
	for i, r := range a.rows {
		if r.u.Name == cur {
			a.sel = i
		}
	}
}

func (a *app) current() *Unit {
	if a.sel >= 0 && a.sel < len(a.rows) {
		return a.rows[a.sel].u
	}
	return nil
}

// issues are the unit's checks; property checks only until it is probed.
func (a *app) issues(u *Unit) []Issue { return Check(a.h, u, a.facts[u.Name]) }

func (a *app) checkCell(u *Unit) string {
	if _, ok := a.facts[u.Name]; !ok {
		return dim("·")
	}
	is := a.issues(u)
	n := func(s Severity) int {
		c := 0
		for _, i := range is {
			if i.Sev == s {
				c++
			}
		}
		return c
	}
	switch worst(is) {
	case SevFail:
		return red(fmt.Sprintf("✗ %d", n(SevFail)))
	case SevWarn:
		return yellow(fmt.Sprintf("! %d", n(SevWarn)))
	}
	return green("ok")
}

func ago(now, t time.Time) string {
	if t.IsZero() {
		return "-"
	}
	d := now.Sub(t)
	if d < 0 {
		d = -d
	}
	switch {
	case d < time.Minute:
		return fmt.Sprintf("%ds", int(d.Seconds()))
	case d < time.Hour:
		return fmt.Sprintf("%dm", int(d.Minutes()))
	case d < 48*time.Hour:
		return fmt.Sprintf("%dh", int(d.Hours()))
	}
	return fmt.Sprintf("%dd", int(d.Hours()/24))
}

func (a *app) sinceCell(r row) string {
	u, now := r.u, a.h.Now
	if u.Kind == "timer" {
		if u.NextElapse.IsZero() {
			return "-"
		}
		return "next " + u.NextElapse.Format("01-02 15:04")
	}
	if r.child {
		mark := green("✓")
		if u.Result != "success" && u.Result != "" {
			mark = red("✗")
		}
		return "last " + mark + " " + ago(now, u.StateChange)
	}
	return ago(now, u.StateChange)
}

func activeCell(u *Unit) string {
	s := u.Sub
	if u.Kind == "timer" && u.Active == "active" {
		s = "waiting"
	}
	switch u.Active {
	case "failed":
		return red(s)
	case "active":
		return green(s)
	}
	return dim(s)
}

var mainKeys = [][2]string{
	{"↑↓", "move"}, {"/", "search"}, {"f", "filter"}, {"s", "start"}, {"S", "stop"}, {"R", "restart"},
	{"space", "enable/disable"}, {"l", "journal"}, {"enter", "details & fixes"}, {"e", "edit drop-in"},
	{"w", "save"}, {"c", "cat"}, {"r", "reload"}, {"?", "help"}, {"q", "quit"},
}

func (a *app) dirtyCount() int {
	n := 0
	for _, d := range a.edits {
		if d.Dirty() {
			n++
		}
	}

func (a *app) titleLine() string {
	svc, tim, failed := 0, 0, 0
	for _, u := range a.h.Units {
		if u.Kind == "timer" {
			tim++
		} else {
			svc++
		}
		if u.Active == "failed" {
			failed++
		}
	}
	t := inv(bold(" svcman ")) + " " + bold(a.h.Login+"@"+hostOf(a.h.r.Label())) +
		dim(fmt.Sprintf("  %d services, %d timers  ·  filter: %s", svc, tim, filters[a.filter]))
	if a.search != "" {
		t += dim("  ·  search: ") + a.search
	}
	if failed > 0 {
		t += "  " + red(fmt.Sprintf("%d failed", failed))
	}
	if a.h.SysState != "running" {
		t += "  " + yellow(a.h.SysState)
	}
	if n := a.dirtyCount(); n > 0 {
		t += "  " + yellow(fmt.Sprintf("● %s unsaved (w to save)", plural(n, "drop-in")))
	}
	return t
}

func (a *app) render(promptLines []string) []string {
	w, h := a.scr.size()
	keys := keybar(w, mainKeys)
	fixed := 2 + 1 + len(keys)
	if promptLines != nil {
		fixed += len(promptLines) - 1
	}
	listH := max(3, h-fixed)
	nameW := 28
	lines := []string{a.titleLine()}
	lines = append(lines, dim(fmt.Sprintf(" %-*s %-10s %-9s %-6s %8s  %s", nameW, "UNIT", "ACTIVE", "ENABLED", "CHECK", "RESTARTS", "SINCE")))
	if a.sel < a.off {
		a.off = a.sel
	}
	if a.sel >= a.off+listH {
		a.off = a.sel - listH + 1
	}
	for i := a.off; i < len(a.rows) && i < a.off+listH; i++ {
		r := a.rows[i]
		name := r.u.Name
		if r.child {
			name = "  └ " + name
		}
		restarts := "-"
		if r.u.Kind == "service" {
			restarts = fmt.Sprint(r.u.NRestarts)
		}
		l := " " + padRight(fit(name, nameW), nameW) + " " + padRight(activeCell(r.u), 10) + " " +
			padRight(r.u.FileState, 9) + " " + padRight(a.checkCell(r.u), 6) + " " + fmt.Sprintf("%8s", restarts) + "  " + a.sinceCell(r)
		l = fit(l, w)
		if i == a.sel {
			l = inv(padRight(stripSGR(l), w))
		}
		lines = append(lines, l)
	}
	if len(a.rows) == 0 {
		lines = append(lines, dim("   no units match (f: filter, /: search)"))
	}
	for len(lines) < 2+listH {
		lines = append(lines, "")
	}
	if promptLines != nil {
		lines = append(lines, promptLines...)
	} else {
		lines = append(lines, " "+a.status)
	}
	return append(lines, keys...)
}

// stripSGR removes colour codes so the selected row can be shown inverted.
func stripSGR(s string) string {
	var b strings.Builder
	for i := 0; i < len(s); i++ {
		if s[i] == 0x1b && i+1 < len(s) && s[i+1] == '[' {
			j := i + 2
			for j < len(s) && s[j] != 'm' {
				j++
			}
			i = j
			continue
		}
		b.WriteByte(s[i])
	}
	return b.String()
}

// ensureRoot asks for the sudo password when needed; false when there is no root.
func (a *app) ensureRoot() bool {
	if a.h.canRoot() {
		return true
	}
	if a.h.Priv != PrivPassword {
		a.status = red("This needs root, and " + a.h.Login + " has no sudo on this host.")
		return false
	}
	a.scr.suspend()
	fmt.Fprintln(os.Stderr)
	a.h.askPassword("[sudo] password for " + a.h.Login + " on " + a.h.r.Label() + " (empty = cancel): ")
	a.scr.resume()
	if !a.h.canRoot() {
		a.status = yellow("Cancelled: no sudo password.")
		return false
	}
	return true
}

var verbWords = map[string][3]string{ // verb: question, progressive, past
	"start": {"Start", "Starting", "started"}, "stop": {"Stop", "Stopping", "stopped"},
	"restart": {"Restart", "Restarting", "restarted"}, "enable": {"Enable", "Enabling", "enabled"},
	"disable": {"Disable", "Disabling", "disabled"},
}

// doAction asks, runs systemctl <verb> as root, re-reads the unit and shows
// the journal when it ends up failed.
func (a *app) doAction(base func([]string) []string, verb string) {
	u := a.current()
	if u == nil {
		return
	}
	w := verbWords[verb]
	if k := a.ask(base, w[0]+" "+u.Name+"?", "y = yes   any other key = no"); k != 'y' && k != 'Y' {
		a.status = "Cancelled."
		return
	}
	if !a.ensureRoot() {
		return
	}
	a.status = w[1] + " " + u.Name + "…"
	a.scr.draw(base(nil), -1, -1)
	_, err := a.h.action(verb, u.Name)
	names := append([]string{u.Name}, u.Triggers...)
	_ = a.h.refresh(names...)
	a.recheck(u.Name)
	a.rebuild()
	if err != nil {
		a.status = red(verb + " failed: " + err.Error())
	} else {
		a.status = green(u.Name + " " + w[2] + ".")
		if verb == "enable" && a.h.Unit(u.Name).Active != "active" {
			a.status += " Press s to start it now."
		}
	}
	if nu := a.h.Unit(u.Name); nu != nil && nu.Active == "failed" {
		a.showJournal(nu, 10)
	}
}

// recheck re-probes one unit (if it was probed before or details are open).
func (a *app) recheck(name string) {
	u := a.h.Unit(name)
	if u == nil {
		return
	}
	if m, err := a.h.probe([]*Unit{u}); err == nil {
		a.facts[name] = m[name]
	}
}

func (a *app) toggleEnable(base func([]string) []string) {
	u := a.current()
	if u == nil {
		return
	}
	switch u.FileState {
	case "enabled", "enabled-runtime":
		a.doAction(base, "disable")
	case "disabled":
		a.doAction(base, "enable")
	default:
		a.status = u.Name + " is " + u.FileState + "; only enabled/disabled units can be toggled."
	}
}

func (a *app) reload() {
	if a.dirtyCount() > 0 {
		if k := a.ask(a.render, "Reload and discard unsaved drop-in edits?", "y = yes   any other key = no"); k != 'y' && k != 'Y' {
			return
		}
	}
	a.status = "Reloading…"
	a.scr.draw(a.render(nil), -1, -1)
	h, err := loadHost(a.h.r)
	if err != nil {
		a.status = red("reload failed: " + err.Error())
		return
	}
	h.pw, h.journalRoot = a.h.pw, a.h.journalRoot
	a.h = h
	a.edits = map[string]*DropIn{}
	a.probeDefault()
	a.rebuild()
	a.status = "Reloaded " + plural(len(h.Units), "unit") + "."
}

// probeDefault probes the units audit would check.
func (a *app) probeDefault() {
	a.facts = map[string]*UnitFacts{}
	if m, err := a.h.probe(auditUnits(a.h, false)); err == nil {
		a.facts = m
	} else {
		a.status = red("checks failed: " + err.Error())
	}
}

func (a *app) searchPrompt() {
	v, ok := a.prompt(a.render, "Search unit names (empty = clear)", a.search, nil)
	if ok {
		a.search = strings.TrimSpace(v)
		a.rebuild()
	}
}

func (a *app) confirmQuit() bool {
	if a.dirtyCount() == 0 {
		return true
	}
	switch a.ask(a.render, "You have unsaved drop-in edits.", "s = save and quit   d = discard and quit   esc = cancel") {
	case 's', 'S':
		return a.save()
	case 'd', 'D':
		return true
	}

var keyRe = regexp.MustCompile(`^[A-Za-z][A-Za-z0-9]*$`)

// parseEntryInput reads "Key=value" or "Section/Key=value".
func parseEntryInput(s, defSection string) (Entry, string) {
	k, v, ok := strings.Cut(strings.TrimSpace(s), "=")
	k, v = strings.TrimSpace(k), strings.TrimSpace(v)
	if !ok || k == "" {
		return Entry{}, "write Key=value (or Section/Key=value)"
	}
	sec := defSection
	if a, b, ok := strings.Cut(k, "/"); ok {
		sec, k = strings.TrimSpace(a), strings.TrimSpace(b)
	}
	if !keyRe.MatchString(k) || !keyRe.MatchString(sec) {
		return Entry{}, "a key is letters and digits, e.g. Restart=always"
	}
	return Entry{sec, k, v}, ""
}

// diffDropIn shows old and new content of one drop-in.
func diffDropIn(d *DropIn) []string {
	out := []string{bold(d.Path)}
	newC := d.Render()
	oldL := strings.Split(strings.TrimRight(d.Orig, "\n"), "\n")
	newL := strings.Split(strings.TrimRight(newC, "\n"), "\n")
	inOld := map[string]bool{}
	for _, l := range oldL {
		inOld[l] = true
	}
	inNew := map[string]bool{}
	for _, l := range newL {
		inNew[l] = true
	}
	for _, l := range oldL {
		if l != "" && !inNew[l] {
			out = append(out, red(" - "+l))
		}
	}
	for _, l := range newL {
		if l != "" && !inOld[l] {
			out = append(out, green(" + "+l))
		}
	}
	if newC == "" {
		out = append(out, yellow(" (file will be deleted)"))
	}
	return append(out, "")
}

		base := func(p []string) []string {
			out := append([]string{}, lines[:min(len(lines), h-len(bar)-len(p))]...)
			out = append(out, p...)
			return append(out, bar...)
		}
		a.scr.draw(base([]string{" " + a.status}), -1, -1)
		k, ok := a.scr.keys.Read()
		if !ok {
			return
		}
		a.status = ""
		validate := func(s string) string {
			_, msg := parseEntryInput(s, defaultSection(u))
			return msg
		}
		switch {
		case k.Name == "up" || k.Rune == 'k':
			sel = max(0, sel-1)
		case k.Name == "down" || k.Rune == 'j':
			sel = max(0, min(len(d.Entries)-1, sel+1))
		case k.Rune == 'a':
			if v, ok := a.prompt(base, "Add setting: Key=value or Section/Key=value  ["+defaultSection(u)+"]", "", validate); ok {
				e, _ := parseEntryInput(v, defaultSection(u))
				d.Entries = append(d.Entries, e)
				sel = len(d.Entries) - 1
				if !knownKey(props, e.Key) && len(props) > 0 {
					a.status = yellow(e.Key + " is not a property systemd reports for this unit; check the spelling.")
				}
			}
		case (k.Name == "enter" || k.Rune == 'c') && sel < len(d.Entries):
			e := d.Entries[sel]
			if v, ok := a.prompt(base, "Change setting", e.Section+"/"+e.Key+"="+e.Value, validate); ok {
				d.Entries[sel], _ = parseEntryInput(v, defaultSection(u))
			}
		case k.Rune == 'D' && sel < len(d.Entries):
			d.Entries = append(d.Entries[:sel], d.Entries[sel+1:]...)
			sel = max(0, min(sel, len(d.Entries)-1))
		case k.Rune == 'w':
			a.save()
		case k.Rune == 'q' || k.Name == "esc" || k.Name == "ctrl-c" || k.Name == "left":
			if d.Dirty() {
				a.status = yellow("Drop-in for " + u.Name + " edited; press w to save.")
			}
			return
		}
	}
}

// save writes every edited drop-in after one confirmation. Returns true when
// nothing is left unsaved.
func (a *app) save() bool {
	var dirty []*DropIn
	var diff []string
	for _, d := range a.edits {
		if d.Dirty() {
			dirty = append(dirty, d)
			diff = append(diff, diffDropIn(d)...)
		}
	}
	if len(dirty) == 0 {
		a.status = "No changes."
		return true
	}
	confirmed := false
	a.pager("Pending drop-in changes", diff, [][2]string{{"y", "write and daemon-reload"}}, false, func(k Key) bool {
		if k.Rune == 'y' || k.Rune == 'Y' {
			confirmed = true
			return true
		}
		return false
	})
	if !confirmed {
		a.status = "Not saved."
		return false
	}
	if !a.ensureRoot() {
		return false
	}
	stamp := time.Now().Format("20060102-150405")
	var msgs []string
	var saved []string
	ok := true
	for _, d := range dirty {
		bk, err := saveDropIn(a.h, d, stamp)
		if err != nil {
			ok = false
			msgs = append(msgs, red(d.Unit+": "+err.Error()))
			continue
		}
		m := green(d.Unit + ": saved")
		if bk != "" {
			m += dim("  backup: " + bk)
		}
		msgs = append(msgs, m)
		saved = append(saved, d.Unit)
		delete(a.edits, d.Unit)
	}
	if len(saved) > 0 {
		_ = a.h.refresh(saved...)
		for _, n := range saved {
			a.recheck(n)
		}
		a.rebuild()
		var running []string
		for _, n := range saved {
			if u := a.h.Unit(n); u != nil && u.Active == "active" && u.Kind == "service" {
				running = append(running, n)
			}
		}
		a.status = strings.Join(msgs, "  ")
		if len(running) > 0 {
			if k := a.ask(a.render, "Restart "+strings.Join(running, ", ")+" so the change takes effect?", "y = restart   any other key = later"); k == 'y' || k == 'Y' {
				if _, err := a.h.action("restart", running...); err != nil {
					msgs = append(msgs, red("restart failed: "+err.Error()))
				} else {
					msgs = append(msgs, green("restarted"))
				}
				_ = a.h.refresh(running...)
				a.rebuild()
			}
		}
	}
	a.status = strings.Join(msgs, "  ")
	return ok
}
